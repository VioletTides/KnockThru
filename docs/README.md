# KnockThru docs

These pages explain how KnockThru works on the inside. To install and use it, read the [main README](../README.md) instead.

- [How knock detection works](knock-detection.md): how KnockThru tells a knock apart from swinging your arms, and where each rule came from.
- [How calibration works](calibration.md): what the calibration walkthrough measures, and how it turns your knocks into thresholds.
- [The test recordings](test-recordings.md): the motion recordings from a Steam Frame that every change gets tested against.
- [How the app fits together](how-the-app-works.md): what runs on the headset, how it switches passthrough, and where your settings live.

Every number in these pages comes from the code or from the test recordings. If you change a threshold, update the page that explains it.
